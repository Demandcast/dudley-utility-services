Rules
Always use the token

Never write a raw pixel value for spacing. Use var(--sp-6), not 24px. This keeps the system adjustable and consistent.

Text flow is locked

Eyebrow-to-heading and heading-to-body are always --sp-4 (16px). Body-to-CTA is always --sp-8 (32px). No exceptions.

Stay on the scale

If you need a value between steps, pick the nearer step. No 18px, 22px, 26px, 30px, 36px, 44px, or 58px. Those are the old chaos.

Section rhythm

--sp-20 (80px) between sections. --sp-16 (64px) from section heading to content. --sp-12 (48px) for container horizontal padding.

Icons

Outlined, gradient-stroked, surveyor-precise.

Every icon is a Remix Icon outline with the DUS teal-to-green gradient as its stroke. Three sizes on the 4px grid. Squared containers only.

Rules
Source and style

Remix Icon (remixicon.com), always the -line suffix variant. Outlined only, never filled or solid.

Stroke

stroke-width="1.2" with stroke-linecap="round" and stroke-linejoin="round". Simple geometric paths, no fills.

Color

DUS gradient teal-to-green via SVG <linearGradient>, horizontal left to right. Never flat single-color icons.

Containers

Squared with --r-md (6px). Never circles, never border-radius: 50%. Coverage badges use solid teal or green backgrounds with white stroke.

Size scale
--icon-sm 24px
--icon-md 40px
--icon-lg 48px

Motifs

Four moves make it DUS.

The survey grid, the route line, the horizon rule, and the corner ticks. Each is drawn from the work itself: plat maps, corridors, section lines.

Survey grid · dark

Every dark field carries the plat grid: fine 44px cells, a heavier section line every fourth. The green horizon anchors the bottom edge.

Survey grid · light

On white it is a whisper, not a pattern. If you notice it before the content, it is too strong.

Route line

Drawn like an alignment sheet: dash-dot centerline, easement corridor, PI monuments, station ticks, parcel lines. One per composition, behind content, never through body text.

Service Overview
Corner ticks

Plat-sheet corners frame the body of print documents. Quiet, structural, surveyor-precise.
